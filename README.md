# VK Certificate Bot

## Описание проекта

VK Certificate Bot — это чат-бот для социальной сети ВКонтакте, предназначенный для автоматизации лидогенерации.


Бот позволяет отслеживать источники переходов пользователей, количество новых лидов, подписки и выданные сертификаты.

---

# Функциональные возможности

## Реализованные функции

### 1. Взаимодействие с пользователем

Бот поддерживает следующий сценарий:

1. Пользователь переходит по рекламной ссылке на чат с ботом.
2. Нажимает кнопку "Начать".
3. Бот проверяет наличие подписки на сообщество.
4. Если пользователь подписан:
   - отправляется сообщение с условиями использования сертификата;
   - отправляется изображение сертификата.
5. Если пользователь не подписан:
   - бот предлагает подписаться на сообщество;
   - отображается кнопка проверки подписки.
6. После успешной проверки подписки пользователь получает сертификат.

---

# Основные возможности

## Проверка подписки

Бот использует VK API:

```
groups.isMember
```

для проверки, является ли пользователь подписчиком сообщества.

---

## Выдача сертификата

После успешной проверки подписки бот автоматически отправляет:

- текст с условиями использования;
- изображение сертификата.

Также реализована защита от повторной выдачи одного сертификата одному пользователю.

---

## Отслеживание источников переходов

Бот поддерживает систему реферальных меток (`ref`).

Каждый источник перехода сохраняется в базе данных.

Пример:

```
vk_post_1     150 пользователей
advert_1      80 пользователей
banner_test   20 пользователей
```

Это позволяет оценивать эффективность рекламных каналов.

---

## Статистика

Администратор может получить статистику работы бота.

Отображается:

- общее количество пользователей;
- количество подписчиков;
- количество выданных сертификатов;
- статистика по источникам переходов.

## bot.py

Основной файл логики бота.

# База данных

В проекте используется SQLite.

Файл базы данных:

```
users.db
```

## Таблица users

Хранит информацию о пользователях.

Поля:

| Поле | Описание |
|-|-|
| id | идентификатор записи |
| vk_id | ID пользователя VK |
| ref | источник перехода |
| first_visit | дата первого взаимодействия |
| subscribed | наличие подписки |
| certificate_sent | факт выдачи сертификата |

---

## Таблица sources

Хранит статистику рекламных источников.

Поля:

| Поле | Описание |
|-|-|
| id | идентификатор |
| ref | название источника |
| users_count | количество пользователей |

---

## Таблица events

Хранит действия пользователей.

Примеры событий:

```
start
subscribe
certificate
```

# Настройка VK Callback API

Для работы бота необходимо:

1. Создать сообщество VK.
2. Включить сообщения сообщества.
3. Создать ключ доступа сообщества.
4. Настроить Callback API.
5. Указать адрес сервера:

```
http://ваш_домен/
```

6. Указать строку подтверждения:

```
66ca59e9
```

После успешной проверки VK начнёт отправлять события боту.
