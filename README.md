# VK Certificate Bot

## Описание проекта

VK-бот для автоматизации лидогенерации.

Основная задача:
- привлечение пользователей через рекламные ссылки;
- проверка подписки пользователя на сообщество VK;
- автоматическая выдача подарочного сертификата после выполнения условия;
- сохранение статистики пользователей и источников переходов.


## Используемые технологии

- Python 3
- Flask
- VK API
- VK Callback API
- SQLite
- vk_api


## Реализованный функционал

### Пользовательская часть:

✅ Запуск диалога с ботом  
✅ Получение параметра рекламной ссылки (`ref`)  
✅ Проверка подписки пользователя на сообщество  
✅ Кнопка проверки подписки  
✅ Выдача сертификата  
✅ Отправка изображения сертификата  


### Серверная часть:

✅ Подключение VK Callback API  
✅ Flask-сервер для обработки событий  
✅ Работа через HTTPS-туннель Tuna  
✅ Обработка события `message_new`  


### База данных:

Используется SQLite.

Хранится:

- VK ID пользователя
- источник перехода (`ref`)
- дата первого обращения
- статус подписки
- факт выдачи сертификата
